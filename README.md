# ETF Surf

**나의 첫 ETF, 이해하고 선택하기.**
초보 투자자가 질문에 답하고, 선정 이유가 있는 ETF 후보를 살펴보고, 최대 3개 상품을 비교하는 정적 웹사이트입니다.

## 구현된 기능
- 목적·사용 시점·손실 수용 정도·관심 시장에 관한 네 가지 질문
- 공개된 규칙에 따른 후보 안내, 추천하지 않는 결과와 해당 상품 미등록 상태
- 9개 ETF 검색·종류 필터·상품 상세
- 최대 3개 비교: 공통 기간의 가격 수익률·최대낙폭, 총보수·순자산·거래량
- 일부 분배금 지급 내역과 항목별 공식 출처·자료 날짜
- 8개 입문 학습 콘텐츠, 규칙·데이터 설명 페이지
- 추천 후보별 선정 이유·주요 위험·확인할 지표
- 후보 ETF를 골라 매월 투자한 과거 가격 시나리오 계산
- 상품 구조·가격 영향 요인·확인 항목을 설명하는 상세 가이드
- 같은 지수·유형의 두 상품 비교 연결과 항목별 자료 확보 상태

학습 후보 안내이며 개인별 투자 적합성 판단, 매수 지시, 예상 수익률 또는 투자 비중을 제공하지 않습니다.
국내 상장 ETF 9개만 등록되어 있어 전체 시장을 대표하는 추천 목록이 아닙니다.
질문은 서버로 보내거나 저장하지 않으며 새로고침하면 답변과 비교 선택이 초기화됩니다.

## 실행·검증
`docs/index.html`을 브라우저에서 열거나 저장소 루트에서 `python3 -m http.server 8000` 실행 후 `http://localhost:8000/docs/`에 접속합니다.

```sh
node tests/surf.cjs
node --check docs/app.js
node --check docs/rules.js
```
별도 패키지 설치·API 키·빌드 과정이 없습니다.

## 데이터와 한계
`docs/prices.js`는 기존 KOSPI200-ETF-LAB에서 수집한 NAVER 일별 종가·거래량 스냅샷(2026-09-23까지)입니다.
`docs/fundamentals.js`는 2026-09-24 확인한 운용사·거래소 기본 정보 및 일부 지급 내역입니다.
기본 정보는 항목마다 자료 기준일이 다르며 일부는 수년 전 자료입니다. 현재 값으로 보장하지 않습니다.
원래 출처 URL·단위·기준일을 데이터에 유지하고 상세 화면에 표시합니다.
가격 갱신 코드는 `scripts/update_prices.py`, 예약 작업은 `.github/workflows/update-prices.yml`입니다.
평일 한국시간 19:23 실행하도록 설정했습니다. 예약 실행은 이 파일이 기본 브랜치에 병합된 뒤 동작합니다.
현재 개발 브랜치의 설정만으로 예약 실행이나 공개 배포가 활성화된 것은 아닙니다.
수동 실행은 `python3 scripts/update_prices.py`이며 추가 패키지가 필요 없습니다.
9개 ETF 날짜·가격·거래량과 과거 이력을 모두 검증한 뒤 가격 파일을 교체합니다.
한 종목이라도 실패하면 기존 가격은 보존하고 `docs/update-status.js`에 실패 상태를 기록합니다.
기본 정보·분배금 확인일은 가격 수집으로 바꾸지 않습니다. 7일 이상 지난 가격도 화면에 안내합니다.

최근 1년은 마지막 관측일에서 달력상 12개월 전 이하의 가장 가까운 관측 종가부터 계산합니다.
수익률 = 마지막 가격 / 시작 가격 - 1. 최대낙폭 = min(각 가격 / 당시까지 최고 가격 - 1).
분배금 재투자·세금·매매비용은 계산하지 않습니다. 공급자 과거 가격 조정 이력이 미검증이므로 총수익률로 해석하지 않습니다.
추적오차·NAV·호가 스프레드는 데이터가 없어 제공하지 않습니다. 가격 변화로 운용 능력 순위를 매기지 않습니다.
분배금은 PLUS 고배당주 8건, PLUS 200 7건의 일부 이력만 있으며 연간 분배율로 변환하지 않습니다.
투자 시나리오는 12·36·60회 월 납입을 선택합니다. 마지막 관측 월을 포함해 해당 월 수만큼 각 월 첫 관측 거래일에 매수하며 마지막 월은 관측일까지만 평가합니다. 12회는 월 투자금의 정확히 12배를 납입합니다. 실제 시작·종료일을 표시하며 이력이 부족하면 계산하지 않습니다. 정수 매수 후 잔여 현금은 다음 납입 때 함께 사용합니다. 결과에는 누적 투자금·평가금액·손익·입금 효과를 제외한 최대낙폭을 보여주지만 실제 체결·미래 예측은 아닙니다.

## 후보 안내 규칙
1. 1년 이내 사용 또는 원금 손실 수용 불가 → 상품 후보 없음.
2. 변동이 부담스러움 → 국내 국고채 ETF 학습 후보. 다른 선호보다 우선하며 금리·원금 손실 위험을 설명.
3. 그 외 분배금 관심 → 배당 전략 + 관심 시장, 나머지 → 대표지수 주식 ETF + 관심 시장.
4. 결과는 종목코드 순서. 금 선물·산업 집중 ETF는 탐색만 가능, 자동 후보에서 제외.

규칙은 프로젝트의 학습용 분류 기준이며 투자 기간이 안전성을 보장한다는 뜻이 아닙니다.

## 파일 구성
- `docs/index.html`, `style.css`, `app.js`: 화면 및 접근 가능한 기본 인터랙션
- `docs/rules.js`: 질문 검증·후보 규칙·성과 계산
- `docs/data-core.js`: 기존 프로젝트에서 재사용한 데이터 검증/어댑터
- `docs/prices.js`, `fundamentals.js`: 출처가 포함된 저장 자료
- `tests/surf.cjs`: 81개 답변 조합, 누락·충돌·빈 결과·계산·화면 검증

## 배포
상세 비교 연결은 추종지수·자산 종류·지역·전략·상품유형이 모두 같은 등록 상품을 종목코드 순으로 보여줍니다.
현재 KOSPI200 4개 ETF 사이에 연결이 있으며, 다른 상품은 비교 대상 미등록 안내를 제공합니다.
비교 버튼은 기존 선택을 해당 두 상품으로 교체하며 화면에 이를 안내합니다.
상품 설명은 구조에 대한 교육용 해석으로, 당일 수익률 기여도 분석이나 미래 예측이 아닙니다.

GitHub Pages에서 배포할 브랜치의 `/docs` 폴더를 선택하면 됩니다. 실제 공개 주소와 배포 상태는 저장소의 Pages 설정에서 확인하세요.
개발은 `codex/` 브랜치에서 진행하며 기존 KOSPI200-ETF-LAB은 변경하지 않습니다.
