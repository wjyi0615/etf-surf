# ETF Surf

**나의 첫 ETF, 이해하고 선택하기.** 국내 상장 ETF의 투자 대상·구성·위험을 읽고, 직접 조건을 골라 비교하는 입문자용 학습 웹사이트입니다.

[공개 사이트](https://wjyi0615.github.io/etf-surf/) · [배포 기록](https://github.com/wjyi0615/etf-surf/actions/workflows/pages.yml) · [가격 갱신 기록](https://github.com/wjyi0615/etf-surf/actions/workflows/update-prices.yml)

> main 배포본 기준입니다. 국내 상장 ETF 32개, 구성자료, 차분한 파란색 디자인을 제공합니다. 배포 완료 여부는 위 배포 기록에서 확인할 수 있습니다.

## 현재 범위

| 구분 | 제공 범위 |
|---|---|
| 상품 | 국내 상장 ETF 32개. 전체 시장이나 인기 순위가 아닙니다. |
| 가격 | 기존 20개에 일별 종가·거래량. 추가 12개는 가격 미확보입니다. |
| 구성자료 | 27개는 공식 자료의 일부 구성종목·비중, 5개는 투자 구조 설명입니다. |
| 기본 정보 | 확인한 항목만 출처·기준일과 함께 표시합니다. 미확보는 0으로 바꾸지 않습니다. |
| 분배금 | 일부 상품의 일부 지급 기록이며 전체 이력이 아닙니다. |

국내 대표지수·코스닥150, 미국 S&P500·나스닥100, 국내·미국 배당, 채권, CD·KOFR·SOFR 금리형, 금 선물, 반도체를 다룹니다. 일본·유럽 지수 상품은 현재 범위에서 제외했습니다. ‘미국’은 상장 국가가 아니라 투자 대상 시장입니다.

구성자료는 서로 다른 과거 시점의 자료입니다. **32개 모두의 최신·전체 보유 비중을 제공한다는 뜻은 아닙니다.** 공식 자료의 날짜나 항목이 불명확하면 비중을 추정하지 않고 구조 설명과 확인 사유를 표시합니다.

## 이용 흐름

**관심 주제 → 세부 유형 → 상품 상세 → 근거자료 → 최대 3개 비교**

- **홈·나의 ETF 찾기:** 여섯 주제에서 시장과 세부 유형을 직접 고릅니다. 구조와 위험 설명을 펼쳐볼 수 있습니다.
- **둘러보기:** 이름·운용사·코드 검색과 자산·시장 필터를 제공합니다. 검색 조건은 URL에 저장됩니다.
- **상품 상세:** 투자 대상 → 영향 요인 → 위험 → 구성자료 순서로 읽습니다. 날짜와 공식 원문을 함께 표시합니다.
- **비교:** 기본 정보와 확인된 비용·환헤지·분배 방식 등을 비교합니다. 같은 지수 상품은 확인된 분류가 일치할 때만 연결합니다.
- **학습·시나리오:** ETF 기초 개념과 가격 이력이 충분한 상품의 과거 적립식 계산을 제공합니다.
- **자료 현황:** 상세 페이지·하단·가격 안내에서 접근합니다. 상품별 출처와 재확인 필요 항목을 확인할 수 있습니다.

채도 낮은 파랑, 밝은 중립 배경, 흰 카드를 사용합니다. PC·모바일 레이아웃, 키보드 초점, 선택 문구를 지원합니다. 기존 스크린샷은 이전 디자인 기록이며 현재 색상은 로컬 실행으로 확인하세요.

## 로컬 실행

저장소 루트에서 실행합니다. 별도 빌드나 API 키가 필요하지 않습니다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory docs
```

[로컬 홈](http://127.0.0.1:8000/) · [둘러보기](http://127.0.0.1:8000/#/explore) · [구성자료 예시](http://127.0.0.1:8000/#/etf/232080)

Python 3는 미리보기·가격 갱신, Node.js는 JavaScript 테스트에 사용합니다. 파일 직접 열기보다 HTTP 미리보기를 권장합니다.

## 검증

```sh
nodetests/surf.cjs
python3 -m unittest discover -s tests -p 'test_*.py' -v
node --check docs/app.js
node --check docs/rules.js
node scripts/audit_data.cjs > /tmp/etf-data-health.json
```

상품 검색·필터·URL 복원, 32개 상세 구성자료, 공통 기간 계산, 미확보 처리, 가격 갱신 실패 시 기존 자료 보존을 검증합니다. 중단된 추천 로직도 기존 81개 답변 조합 회귀 테스트에 남아 있습니다. 자료 점검 보고서는 출처·날짜 오류가 있으면 종료 코드 1을 반환할 수 있습니다.

실제 브라우저 검증과 정적 감사의 한계는 [UI-VERIFICATION.md](UI-VERIFICATION.md)에 기록합니다.

## 데이터와 계산

- 가격 수익률: `마지막 가격 / 시작 가격 - 1`.
- 최대낙폭: `min(각 가격 / 당시까지 최고 가격 - 1)`.
- 최근 1년은 마지막 관측일의 12개월 전 이하에서 가장 가까운 종가를 사용합니다. 비교는 선택 상품 모두의 공통 거래일 기준입니다.
- 가격 미확보 상품이 비교에 포함되면 공통 기간 성과·차트를 계산하지 않습니다. 기본 정보 비교는 가능합니다.
- 분배금 재투자·세금·매매비용은 반영하지 않습니다. 공급자 가격 조정 이력을 독립 검증하지 않아 총수익률로 해석할 수 없습니다.
- NAV·추적오차·호가 스프레드는 제공하지 않습니다. 다른 지수의 수익률 차이를 운용 능력 순위로 해석하지 않습니다.
- 적립식 시나리오는 12·36·60회 납입을 지원합니다. 월 첫 관측 종가로 정수 단위 매수하고 잔여 현금을 이월하며, 이력이 부족하면 계산하지 않습니다.

가격은 NAVER 저장 자료, 설명·기본 정보·구성자료는 상품별 공식 출처를 사용합니다. 자료 기준일과 출처 확인일은 다릅니다. 오래된 문서를 다시 열었다고 최신 보유내역이 되는 것은 아닙니다. 같은 지수의 다른 ETF 비중을 복제하지 않습니다.

## 갱신과 배포

- 가격 갱신: 기존 20개만 대상으로 평일 한국시간 19:23 예약 실행합니다. GitHub 예약 실행은 지연될 수 있습니다.
- 실패하면 마지막 정상 가격을 보존하고 실패 상태를 표시합니다.
- 가격 수집은 구성자료·보수·분배금의 날짜를 갱신하지 않습니다. 추가 12개의 가격도 자동으로 채우지 않습니다.
- 수동 가격 수집: `python3 scripts/update_prices.py`.
- Pages는 main 변경, 가격 갱신 작업 완료 또는 수동 실행을 통해 배포합니다. 작업 브랜치의 미리보기와 공개 배포는 별개입니다.

## 운영 범위와 브랜치
