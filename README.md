# ETF Surf

초보 투자자가 ETF를 이해하고 비교 후보를 찾는 여행.

## 현재 상태
독립 프로젝트의 초기 기획과 시작 화면을 준비했습니다. 추천 기능과 상품 데이터는 아직 연결하지 않았습니다.
기존 KOSPI200-ETF-LAB 저장소와 사이트는 유지합니다.

## 첫 버전의 흐름
투자 목적·기간·손실 수용 정도 확인 → 이유가 있는 ETF 후보 → 상품 비교 → 용어 학습.
후보 선정 이유와 주요 위험, 자료 출처·기준일을 함께 표시합니다.
세부 범위는 [PROJECT.md](PROJECT.md)를 참고하세요.

## 시작 화면 확인
`docs/index.html`을 브라우저에서 열면 됩니다. 외부 패키지 설치가 필요 없습니다.
